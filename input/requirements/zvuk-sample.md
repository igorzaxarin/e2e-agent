# Требования к сервису «Звук» (демонстрационный набор)

> Учебный набор требований. Содержит намеренные пробелы и противоречия, чтобы проверять,
> как агенты выявляют неоднозначности, а не додумывают поведение.

## Авторизация и онбординг

- **REQ-01.** Регистрация выполняется по номеру телефона. После отправки номера пользователь
  получает SMS с кодом из 4 цифр. Повторная отправка кода доступна через 60 секунд.
- **REQ-02.** После подтверждения кода создаётся аккаунт, пользователь попадает на экран онбординга
  с выбором музыкальных жанров. Для продолжения необходимо выбрать не менее 3 жанров.
- **REQ-03.** На основе выбранных жанров на главном экране формируется блок «Рекомендации».

## Поиск и воспроизведение

- **REQ-04.** Поиск выполняется по трекам, исполнителям, альбомам и плейлистам. Результаты
  сгруппированы по вкладкам «Треки», «Исполнители», «Альбомы», «Плейлисты».
- **REQ-05.** При запуске трека разворачивается плеер, в котором отображаются обложка, название
  трека, имя исполнителя и таймлайн воспроизведения.
- **REQ-06.** Пользователь может добавить трек в очередь действием «Играть следующим». Добавленный
  трек занимает позицию сразу после текущего. Порядок очереди сохраняется.

## Коллекция и плейлисты

- **REQ-07.** Лайк трека добавляет его в раздел «Мне нравится». Счётчик треков в коллекции
  увеличивается на единицу.
- **REQ-08.** Пользователь может создать плейлист. Длина названия — до 100 символов. По умолчанию
  плейлист приватный.
- **REQ-09.** Трек можно добавить в плейлист из плеера и из результатов поиска.
- **REQ-10.** Созданные плейлисты доступны в разделе «Моя коллекция» → «Плейлисты» и отсортированы
  по дате последнего изменения.
- **REQ-11.** Скачивание плейлиста для офлайн-прослушивания доступно только пользователям с активной
  подпиской.

## Сессия и устойчивость

- **REQ-12.** При выходе из аккаунта локальные данные плеера очищаются.
- **REQ-13.** При обрыве сети во время воспроизведения отображается сообщение о проблеме соединения
  и выполняется попытка переподключения.
- **REQ-14.** При повторном входе по тому же номеру телефона аккаунт восстанавливается: плейлисты и
  лайки пользователя сохраняются.
